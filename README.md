# 🐉 Lesedrache

Lesen lernen für Erstklässler — die **Tastatur ist das Spielfeld**.

Der Drache macht einen Laut. Das Kind sucht die Taste. Aus dem Ei
schlüpft ein Wesen, das in seiner Welt bleibt. Aus Buchstaben werden
Silben, aus Silben Wörter — aber immer nur aus dem, was es schon
erobert hat.

**Kein Multiple Choice. Kein rotes Kreuz. Keine Elterneinstellung, welche
Buchstaben dran sind** — die App merkt das selbst und führt neue erst ein,
wenn die alten sitzen.

## Spielen

```bash
npm install
npm run dev
```

## Tasten

| Taste | Was passiert |
|---|---|
| Buchstabe | diesen Buchstaben jagen |
| `⎵` Leertaste | Aufgabe noch einmal hören |
| `Esc` | zurück |

Eine falsche Taste ist kein Fehler: Sie sagt ihren eigenen Laut, und das
Ei bekommt einen Riss mehr. Suchen bringt ihn dem Schlüpfen näher.

## Eltern-Bereich

Zahnrad oben rechts **1,5 Sekunden gedrückt halten**. Dort steht, welche
Buchstaben schon sitzen — und man kann die Sprachausgabe-Stimme wechseln.
