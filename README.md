# 🐉 Lesedrache

Lesen lernen für Erstklässler — Lautsynthese als Spiel, bedienbar rein
über die Tastatur.

## Spielen

```bash
npm install
npm run dev
```

## Tasten

| Taste | Was passiert |
|---|---|
| `⎵` Leertaste | Laute bzw. Wort noch einmal hören |
| `⏎` Enter | Laute zusammenziehen — der Drache pustet |
| `1` `2` `3` | Bild auswählen |
| Buchstabentaste | diesen einen Laut noch einmal hören |
| `Esc` | zurück |

## Eltern-Bereich

Zahnrad oben rechts **1,5 Sekunden gedrückt halten**. Dort stellt man ein,
welche Buchstaben in der Klasse schon dran waren.
